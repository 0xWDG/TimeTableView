# Sample Timetable View

This project demonstrates a sample timetable view implementation.

This is a simple example because [@PaulRWillis](https://github.com/PaulRWillis) talked about it for the [SwiftLeeds](https://swiftleeds.co.uk) conference [app](https://apps.apple.com/nl/app/swiftleeds/id1595490143).

This code is provided as-is, and you may be need to modify it to fit your own requirements.
